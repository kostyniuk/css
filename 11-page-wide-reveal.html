Range names

entry and exit are roughly the element crossing a viewport edge.

For normal smaller elements, entry distance is about the element height.

For normal smaller elements, exit distance is about the element height.

cover is the whole overlap trip: viewport height plus element height.

So cover 50% is halfway through the full visible journey.

Page-wide reveal

Every text element uses the same scroll-driven reveal.

First section

The animation is not attached to the page itself.

Second section
